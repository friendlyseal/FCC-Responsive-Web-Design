Arrays

FreeCodeCamp defines Arrays as "[...] a fundamental data structure, and an important part of most programming languages. In Python, they are containers which are able to store more than one item at the same time. Specifically, they are an ordered collection of elements with every value being of the same data type (Source). An example of an array may look like this:

fruits = ['banana', 'apple', 'pear']
numbers = [54, 32, 68]

Here an array called "fruits" is declared with three string values. A print call like print(fruits[0]) would output 'banana'. Another array called numbers is declared with three integer values. A print call like print(numbers[0] - numbers[1] would output the integer 22 (the difference from 54 - 32).

  • Pros: Functionality, fast access, memory efficiency
  • Cons: Fixed Sizes: not easily added to or subtracted from

    In the simplest terms, pointers are variables that hold the memory address of another variable. One common application you'll see is the Two Pointer method, where one pointer will start at one end of an array, another will start at the other end, and the pointers will check for a condition while moving towards the center.

    left_pointer = 0
    right_pointer= (len(array) - 1)

    Then the pointers will check for a condition, and if it is not met, would continue working through the array until left_pointer == right_pointer, signifying that each value in the array was checked

    while left_pointer < right_pointer:
    {check condition}
    left_pointer += 1
    right_pointer -= 1
  • Pros: Memory efficiency, thoroughness
  • Cons: Difficulty in reading
